# 3d-io

Une expérience interactive construite avec React, TypeScript et Vite.

## Prerequisites

- Node.js `>=22.13.0`

## Quick Start

```bash
pnpm install
pnpm dev
pnpm build
```

Le code de l’application se trouve dans `app/`. Le projet s’exécute entièrement
dans le navigateur et ne nécessite ni serveur ni base de données.

## Useful Commands

- `pnpm dev`: démarrer le développement local
- `pnpm build`: vérifier les types et produire la version de production
- `pnpm preview`: prévisualiser la version de production
- `pnpm lint`: vérifier la qualité du code
